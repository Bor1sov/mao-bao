# 🍵 Mao Bao — Чайный магазин

**Mao Bao** — это современное веб-приложение для любителей чая. Проект представляет собой полноценную платформу с каталогом товаров, системой отзывов и разграничением прав доступа для разных ролей пользователей.

На данный момент проект работает в режиме **Fullstack-мока** (вся логика и база данных эмулируются на стороне клиента), но архитектура полностью готова к подключению реального бэкенда.

---

## 📖 О проекте

Приложение позволяет пользователям просматривать каталог чая, оставлять отзывы и ставить оценки. Для администраторов и модераторов предусмотрены отдельные панели управления.

### ✨ Основные возможности:
*   **Каталог товаров:** Красивые карточки чая с фотографиями, описанием и ценой.
*   **Отзывы:** Авторизованные пользователи могут оставлять отзывы к товарам. Отзывы проходят обязательную модерацию.
*   **Тёмная тема:** Встроенный переключатель светлой/тёмной темы оформления (с сохранением выбора в браузере).
*   **Регистрация и Авторизация:** Возможность создать аккаунт и войти в систему.
*   **Ролевая модель:**
    *   `user` — просмотр каталога, оставление отзывов.
    *   `moderator` — одобрение или отклонение отзывов пользователей.
    *   `admin` — управление товарами (CRUD), назначение ролей пользователям.

## 🛠 Технологический стек (Frontend)

*   **React 18** + **TypeScript** — основа интерфейса.
*   **Vite** — сверхбыстрый сборщик.
*   **React Router v6** — маршрутизация и защита роутов (`ProtectedRoute`).
*   **Context API** — управление состоянием авторизации (`AuthContext`) и темы (`ThemeContext`).
*   **LocalStorage** — эмуляция базы данных (данные не пропадают при перезагрузке страницы).
*   **CSS-переменные** — для реализации тёмной темы и легкой кастомизации стилей.
*   **Шрифт Inter** — современная типографика, близкая к стилю Т-Банка.
